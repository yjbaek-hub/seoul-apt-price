# 2021~2026년 서울 아파트 매매가 변화 분석

**▶ 발표 자료 바로 보기: https://seoul-apt-price.pages.dev**

스마트시티 융합기술세미나 | 과제2 — **"지난 5년간 서울시 전세 또는 매매가 가격 변화를 분석하시오."**

서울 25개 자치구의 아파트 매매 실거래 **235,080건**(2021.09 – 2026.08, 60개월)으로 5년간 서울 아파트값의 변화를
**① 거래가격과 거래량 ② 입지 ③ 단지 특성(준공 연도·용적률)** 세 방향으로 분석한 웹 발표 자료입니다.

> **한 줄 요약** — 지난 5년 서울 아파트값은 금리 급등기에 전체 하락(−24.6%) 후 점차 회복해 2026.08 기준 5년 전보다 9.2% 상승했다.
> 그러나 상승의 크기와 내용은 입지(성동구 +33.4% ~ 도봉구 −14.1%), 가격대(25억 초과 +31.1% ~ 9억 이하 +0.3%),
> 단지 특성(저밀도의 40년 이상 노후 아파트가 최대 상승폭)에 따라 크게 달랐다.

## 분석 코드 (`scripts/`)

원본 데이터와 API 키는 저장소에 넣지 않았습니다. 키는 저장소 폴더 바로 바깥(상위 폴더)의 `.env` 파일에서 읽습니다
(`DATA_GO_KR_KEY`, `KAKAO_REST_KEY`, `VWORLD_KEY`). 원본 실거래 자료는 `collect.js`로 다시 받을 수 있습니다.

| 순서 | 파일 | 하는 일 |
|---|---|---|
| 1 | `collect.js` → `raw_to_csv.py` | 국토교통부 실거래가 API로 25개 구 × 60개월 수집 → CSV |
| 2 | `geocode.py` | 주소 → 좌표·행정동 (카카오) |
| 3 | `households.py`, `kapt.py` | 단지 세대수 (건축물대장 · K-apt) |
| 4 | `far.py`, `far_fill.py` | 단지 용적률 (건축물대장, 없으면 연면적 ÷ 대지면적) |
| 5 | `preprocess.py` | 월별 거래 건수·중위가격 |
| 6 | `fe_index.py`, `repeat_sales.py` | 같은 단지·평형 비교 지수 (서울·구별) |
| 7 | `segments.py` | 가격대·연식·용적률별 지수, 준공 연도 × 용적률 격자 |
| 8 | `make_gu_boundary.py` | 서울 25개 구 경계 (통계청 SGIS 시군구 경계) |
| 9 | `build_monthly.py`, `build_deck.py` | 웹페이지용 데이터 (`web/`) 생성 |

## 분석 방법

같은 단지·같은 전용면적의 거래끼리 비교해 월별 가격 수준을 구한 지수(2021.09 = 100)를 사용했습니다.
그달 팔린 아파트 전체의 중위가격으로 비교하면 어떤 집이 팔렸는지에 따라 값이 달라지는 착시가 생기기 때문입니다
(서울 전체 중위가격은 5년간 −4.6%지만 같은 단지끼리 비교하면 +9.2%).
검증: 2022년 서울 연간 변화 −21.7%로 한국부동산원 공동주택 실거래가격지수(−21.78%)와 거의 같습니다.

- 통계청 SGIS 시군구 경계 · 카카오 로컬 API
- 국토교통부·금융위원회 보도자료 — 부동산 정책 시점
